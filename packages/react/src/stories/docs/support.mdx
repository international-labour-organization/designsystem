# Support

The ILO Design System is developed and maintained by the ILO Department of
Communication and Public Information (DCOMM). If you have questions or
feedback, we'd love to hear from you — send us an email at
[comms-help@ilo.org](mailto:comms-help@ilo.org).

## Report a problem

If you encounter a problem with the Design System, you're welcome to
[create an issue](https://github.com/international-labour-organization/designsystem/issues)
on the Design System GitHub repository. To help us resolve it quickly, please
include:

- Which component or package you were using, and its version
- What you expected to happen and what happened instead
- Steps or a code sample that reproduces the problem
