# ILO Design System React Components

Welcome to the **ILO Design System React Component Library**—a comprehensive collection of reusable, accessible, and brand-compliant components designed to help developers build exceptional web applications that align with the [ILO's Visual Identity](https://brand.ilo.org).

Whether you're building a single-page application, a Next.js site, or any other React-powered project, this component library provides everything you need to create consistent, accessible, and visually cohesive digital experiences.

## What's included

This library offers a complete set of production-ready components, including:

- **Content components** for displaying text, images, videos, and other media
- **Navigation components** for menus, breadcrumbs, and site structure
- **Form components** for user input and data collection
- **Interactive components** like accordions, modals, and tabs
- **Layout components** for structuring your pages
- **React hooks** like `useBreakpoint` for responsive behavior in your own code
- **And much more**—all designed to work seamlessly together

Each component is built with accessibility, performance, and maintainability in mind, ensuring your projects meet the highest standards of web development. The package is published as tree-shakeable ES modules, so your bundle only includes the components you actually use.

## Getting started

Getting started with the ILO Design System for React is straightforward:

- **[Installation](/docs/get-started-installation--docs)** — Install the npm package, set up the styles and fonts, and start importing components.

If you're working with Drupal or another PHP framework instead, the same components are available as a [Twig library](https://twig.ui.ilo.org).

## Brand tools

Beyond components, this Storybook includes a **[Logo Generator](/story/utilities-brand--logos)**—a utility for creating and downloading official ILO logos. Choose the language, color, and size, add an optional subbrand for programme or event branding, and export the result as SVG or PNG.

## Why choose the ILO Design System?

### Brand compliance

Our components are meticulously crafted to be fully compliant with the ILO's Visual Identity guidelines. This means you can build applications with confidence, knowing that every element—from typography to color schemes, spacing to interactions—aligns perfectly with the ILO's brand standards. No more guessing about design decisions or worrying about brand consistency.

### Accessibility first

Accessibility isn't an afterthought—it's built into every component from the ground up. All components follow WCAG 2.1 guidelines and are designed to be usable by everyone, including users with disabilities. This commitment to accessibility ensures your applications are inclusive and reach the widest possible audience.

### Responsive and RTL-ready

The modern web is diverse, and so are our components. Every component is fully responsive, working beautifully on everything from mobile phones to large desktop displays. Additionally, our components support right-to-left (RTL) layouts out of the box, making them perfect for multilingual sites serving languages like Arabic, Hebrew, and others.

### Production-ready

These aren't prototype components—they're battle-tested, production-ready building blocks used across ILO's digital properties, including [ILO Live](https://live.ilo.org) and [The Future of Work Podcast](https://podcast.ilo.org). You're getting the same components that power real-world applications, ensuring reliability and performance.

### Active support and maintenance

The ILO Design System is actively maintained and supported by the ILO's Department of Communication. We're committed to providing long-term support, regular updates, bug fixes, and new features. When you use these components, you're not just getting code—you're getting a partnership in building better digital experiences.

Have questions or need help? Feel free to open an issue on our [GitHub repository](https://github.com/international-labour-organization/designsystem/issues). You can also <a href="mailto:ilonews@ilo.org">contact us by email.</a> We're here to help you succeed.
