# Getting started

This website provides guidance and documentation for the ILO Design System using [React](https://reactjs.org).

## Installation

```bash
$ npm i @ilo-org/react
```

The design system's fonts are published separately. Install them alongside the components:

```bash
$ npm i @ilo-org/fonts
```

## Peer dependencies

The library expects `react` and `react-dom` (version 18 or 19) to be installed in your project.

```bash
$ npm i react react-dom
```

## Usage

Import components directly from the `@ilo-org/react` package.

```typescript
import { Button } from "@ilo-org/react";
```

The package is published as tree-shakeable ES modules, so your bundler will only include the components you actually import.

Hooks are exported from the same entrypoint:

```typescript
import { useBreakpoint } from "@ilo-org/react";
```

## Styles

Import the stylesheet once at the top of your application, along with the fonts:

```typescript
import "@ilo-org/react/styles/index.css";
import "@ilo-org/fonts/font-css/fonts.css";
```

In a Next.js project using the App Router, the root layout (`app/layout.tsx`) is the right place for these imports.

### Sass functions and mixins

If you write Sass, the design system's functions and mixins are available from a
single entrypoint. It emits no CSS of its own, so it is safe to `@use` from every
`.module.scss` without duplicating rules into your bundle.

```scss
@use "@ilo-org/react/styles/scss/helpers" as *;

.thing {
  padding: spacing(4);
  max-width: px-to-rem(1296px);

  @include breakpoint("md", true) {
    display: none;
  }
}
```

## Server components

The components in this library are client components, but they do not ship with the `"use client"` directive. If you're using a framework built on React Server Components, such as the Next.js App Router, re-export the components you need from a module of your own that declares the client boundary:

```typescript
// components/design-system.tsx
"use client";

export { Button, Hero, Footer, Pagination } from "@ilo-org/react";
export { useBreakpoint } from "@ilo-org/react";
```

Then import from that module instead of from `@ilo-org/react` directly:

```typescript
import { Button } from "@/components/design-system";
```
